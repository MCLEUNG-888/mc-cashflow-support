Datos útiles para informar de un error

  • Versión de MC CashFlow

  • Mensaje exacto mostrado
  • Una captura, solo si no contiene información sensible

Protege la información sensible

No envíes contraseñas, números completos de tarjetas de pago, credenciales bancarias, secretos de autenticación ni claves privadas de cifrado. Elimina los datos financieros y personales de las capturas salvo que sean imprescindibles.
